1. Resumen Ejecutivo

Se evalúa la instalación de un sistema fotovoltaico (FV) conectado a la red bajo modalidad Net Billing (Ley 21.118), con batería de litio (LiFePO4) para autoconsumo nocturno y respaldo, en una vivienda de Puerto Montt cuyo consumo promedio es de 93,53 kWh/mes (≈ 1.122 kWh/año).

5. Diseño de Prefactibilidad del Sistema

5.1 Normativa y marco regulatorio

  • Ley 21.118 (Net Billing / Generación Distribuida): autogeneración con ERNC e inyección de excedentes, hasta 300 kW.
  • NCh Elec. 4/2003: instalaciones eléctricas de consumo en baja tensión.
  • Pliego técnico RGR N°02 (SEC) para generación distribuida.
  • Declaración TE-4 ante la SEC por instalador eléctrico autorizado.
  • Solicitud de conexión y medidor bidireccional ante SAESA.
  • Equipos con certificación SEC obligatoria.

5.2 Dimensionamiento del generador fotovoltaico

Rendimiento específico (yield) = HSP x 365 x PR
                               = 3,3 x 365 x 0,78 = 940 kWh/kWp/año

Potencia teórica (100% consumo) = 1.122 / 940 = 1,19 kWp
Potencia adoptada = 3 x 550 W   = 1,65 kWp
Generación anual  = 1,65 x 940  = 1.550 kWh/año  (138% del consumo)

El sobredimensionamiento (1,65 vs 1,19 kWp) cubre pérdidas de batería (round-trip ≈ 90 %), degradación de paneles (0,7 %/año) y la estacionalidad invernal.

5.3 Inversor

Inversor híbrido monofásico 3 kW, con MPPT integrado, gestión de batería de litio y función de respaldo (backup) ante corte de red. Ratio DC/AC conservador que permite ampliación futura.

5.4 Batería de litio

Batería LiFePO4 48V / 100Ah = 5,12 kWh nominales
Energía útil (DoD 90%)      = 4,61 kWh
Autonomía ~ 4,61 / 3,1      = 1,5 días de consumo

Química LiFePO4 por seguridad, vida útil (> 6.000 ciclos) y tolerancia al clima frío. Función: desplazar el autoconsumo al horario nocturno y dar respaldo ante cortes.

8.4 Interpretación

  • El VAN negativo en ambos escenarios indica que, con el consumo actual, el proyecto no genera valor económico al 8 %.
  • La batería agrega ≈ $1,6 MM (compra + reemplazo) que no se recupera: destruye ≈ $1,2 MM de VAN adicional.
  • El problema es de escala: el consumo es demasiado bajo para amortizar el costo fijo de un sistema con almacenamiento.

9. Conclusiones y Recomendaciones

  1. Recurso solar: viable (3,3 kWh/m²/día). Proyecto técnicamente factible y conforme a la normativa.
  2. Económicamente NO es rentable para el consumo actual: VAN negativo, TIR < tasa de descuento, PRI > 18 años.
  3. La batería es una inversión de respaldo/resiliencia, no de retorno. Si el objetivo es puramente económico, se recomienda omitirla.
  4. Para mejorar la viabilidad:
    • Evaluar el sistema si aumenta el consumo (calefacción eléctrica, vehículo eléctrico).
    • Priorizar primero eficiencia energética (LED, aislamiento).
    • Si se requiere respaldo, dimensionar la batería solo a las cargas críticas.
    • Cotizar en firme con al menos 3 proveedores certificados SEC.
